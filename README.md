# AI-TTS

Локальная транспортная основа голосового MVP: Asterisk AudioSocket + Python/FastAPI.

## Статус

Это НЕ готовый голосовой агент. Реализованы TCP framing AudioSocket, UUID сессии, приём PCM16 8 kHz mono, опциональный echo, лимит подключений, таймаут, завершение сессий, health endpoint и тесты протокола. Код требует проверки в целевой среде; реальный звонок пока не подтверждён.

Не реализованы Silero VAD, faster-whisper, Ollama, Piper, диалоговая state machine, barge-in, Bitrix24, 1С и перевод на оператора. Enum состояний и Protocol хуков являются контрактами, а не реализациями этих компонентов. Не используйте для клиентских звонков.

## Запуск

```sh
cp .env.example .env
docker compose up --build
```

Gateway слушает TCP 9092. HTTP health доступен на localhost:8000/health. Используйте один процесс Uvicorn: менеджер сессий хранится в памяти.

## Asterisk

Asterisk устанавливается отдельно на том же Linux-хосте; образ Asterisk намеренно не включён. Проверьте наличие приложения AudioSocket и функции UUID в вашей сборке. Добавьте контекст из asterisk/extensions.conf в существующий dialplan. pjsip.conf.example предназначен только для локальной лаборатории: замените CHANGE_ME, аккуратно объедините настройки с существующими и зарегистрируйте локальный softphone как 6001. Наберите 700.

Для проверки двустороннего звука установите ECHO_AUDIO=true в .env и пересоздайте контейнер. Используйте наушники: echo возвращает ваш звук. В обычном режиме gateway принимает звук, но не отвечает голосом.

127.0.0.1:9092 в dialplan работает только когда Asterisk установлен непосредственно на том же хосте, где опубликован порт Docker. Для другого размещения нужно изменить адрес и сетевые ограничения. Не публикуйте AudioSocket в Интернет: здесь нет аутентификации или TLS. Доступные порты привязаны к localhost.
