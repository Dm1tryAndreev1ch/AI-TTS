# Запуск на MacBook (Apple Silicon)

## Что работает сейчас: текстовый режим

В консоли вы пишете реплики клиента, а агент отвечает текстом. Проверяются LLM (Ollama), state machine, оркестратор и CRM-логика. Микрофон, распознавание речи и озвучивание пока не подключены.

```sh
git clone https://github.com/Dm1tryAndreev1ch/AI-TTS.git
cd AI-TTS
bash scripts/setup_mac.sh      # Homebrew, Ollama, venv, загрузка модели (несколько ГБ)
. .venv/bin/activate
python -m gateway.cli
```

Пример: напишите `сколько стоит артикул X-1`, затем `да` на вопрос о подтверждении. Без `ONEC_URL` и `BITRIX_WEBHOOK` используются выдуманные демо-данные 1С и вывод CRM в консоль. Для реальных сервисов заполните `.env`.

## Проверка, что Ollama использует GPU

```sh
ollama ps
```

В колонке Processor должно быть `100% GPU`. Если `100% CPU`, модель работает медленно.

## Модель

По умолчанию `qwen2.5:7b` (задаётся в `.env` через `OLLAMA_MODEL`). Для MacBook с 8 ГБ памяти выберите модель поменьше, но качество понимания речи будет ниже. Проверьте доступные теги на ollama.com и списком `ollama list`. Если выберете модель с режимом размышлений, возможно, понадобится параметр `think=False` в `OllamaLlm`.

## Голос на Mac: что учесть

- STT: `faster-whisper` на Mac работает только на CPU, без Metal. Для малых моделей (base, small) этого обычно достаточно; whisper.cpp с Metal быстрее на больших моделях.
- TTS: `piper-tts` ставится через `pip` на macOS arm64. Русские голоса: denis, dmitri, irina, ruslan. Лицензию выбранного голоса проверьте отдельно.
- Телефония: Asterisk на macOS неудобен, особенно в Docker Desktop из-за виртуальной машины и RTP. Рекомендация: для телефонии использовать Linux-хост, а Mac оставить для разработки AI-части.

## Ограничения

Тесты используют заглушки и не запускают реальные Ollama, Bitrix24 и 1С. Запуск на реальном Mac не проверялся: скорость ответа модели измерьте сами.
