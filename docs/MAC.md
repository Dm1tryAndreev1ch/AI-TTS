# Запуск на MacBook (Apple Silicon, 16 ГБ)

## Шаг 1: текстовый режим

В консоли вы пишете реплики клиента, а агент отвечает текстом. Проверяются LLM (Ollama), state machine, оркестратор и CRM-логика.

```sh
git clone https://github.com/Dm1tryAndreev1ch/AI-TTS.git
cd AI-TTS
bash scripts/setup_mac.sh      # Homebrew, Ollama, venv, загрузка модели (несколько ГБ)
. .venv/bin/activate
python -m gateway.cli
```

Пример: напишите `сколько стоит артикул X-1`, затем `да` на вопрос о подтверждении. Без `ONEC_URL` и `BITRIX_WEBHOOK` используются выдуманные демо-данные 1С и вывод CRM в консоль.

## Шаг 2: голосовой режим

```sh
bash scripts/setup_voice_mac.sh   # микрофон, Silero VAD, faster-whisper, Piper, русский голос
. .venv/bin/activate
python -m gateway.voice_cli
```

При первом запуске faster-whisper скачивает модель распознавания из интернета, macOS запросит доступ к микрофону для терминала. Цепочка: микрофон, Silero VAD (конец реплики после 0,7 с тишины), faster-whisper, оркестратор, Piper, динамики.

Режим полудуплексный: пока агент говорит или думает, микрофон не слушает, поэтому перебить агента нельзя. Используйте наушники, иначе микрофон может поймать звук из динамиков в начале следующей реплики.

## Настройки для 16 ГБ

- LLM: `qwen2.5:7b` (по умолчанию) и распознавание `small` должны поместиться в память одновременно.
- Для лучшего распознавания попробуйте `WHISPER_MODEL=medium` или `turbo` в `.env`. На CPU они медленнее, задержку замерьте сами.
- Проверка GPU у Ollama: `ollama ps`, в колонке Processor должно быть `100% GPU`.

## Что учесть

- Whisper может «дослышивать» слова в шуме. Кроме VAD и фильтра минимальной длины реплики, защиты от этого нет.
- `faster-whisper` на Mac работает только на CPU, без Metal; whisper.cpp с Metal может быть быстрее.
- Piper распространяется по GPL, у каждого голоса своя лицензия. Проверьте их перед коммерческим использованием.
- Имя голоса `ru_RU-irina-medium` и путь `models/ru_RU-irina-medium.onnx` не проверялись на реальной загрузке. Если загрузка не сработала, скачайте русский голос (доступны denis, dmitri, irina, ruslan) в `models/` и укажите `PIPER_VOICE`.
- Asterisk на macOS неудобен, особенно в Docker Desktop. Для телефонии лучше Linux-хост; Mac подходит для разработки AI-части.

## Ограничения

Тесты используют заглушки для Silero, faster-whisper, Piper и микрофона и не запускают реальные Ollama, Bitrix24 и 1С. Запуск на реальном Mac не проверялся: качество распознавания русской речи и задержку измерьте сами.
