# Телефония: Asterisk + AudioSocket (Linux)

## Схема

```
телефон / softphone -> Asterisk -> AudioSocket (TCP 127.0.0.1:9092, PCM16 8 кГц)
  -> gateway.telephony_cli: ресемплинг до 16 кГц -> Silero VAD -> faster-whisper -> оркестратор (Ollama, 1С, Bitrix24)
  -> Piper -> ресемплинг до 8 кГц -> обратно в Asterisk
```

## Запуск

1. Установите Asterisk на Linux-хост. Проверьте, что модули AudioSocket загружены: `asterisk -rx "module show like audiosocket"`.
2. Добавьте контекст из `asterisk/extensions.conf` в dialplan. Для лабораторного теста возьмите `asterisk/pjsip.conf.example` (замените CHANGE_ME) и зарегистрируйте softphone как 6001.
3. Установите Ollama по инструкции с ollama.com и скачайте модель (`ollama pull qwen2.5:7b`).
4. В корне репозитория: `python -m venv .venv && . .venv/bin/activate && pip install -e '.[voice]'`, затем скачайте русский голос Piper в `models/` (см. `scripts/setup_voice_mac.sh` для команды) и укажите `PIPER_VOICE` в `.env`.
5. Запустите `python -m gateway.telephony_cli`. В консоли появится `AudioSocket слушает 127.0.0.1:9092`.
6. Позвоните с softphone на номер 700.

## Как работает

- Один звонок за раз: модели и VAD общие. Второй одновременный звонок получает hangup.
- AudioSocket не передаёт номер звонящего, поэтому агент спрашивает номер голосом. `TELEPHONY_CALLER_PHONE` задаёт номер жёстко, используйте его только для тестов.
- Режим полудуплексный: пока агент говорит, он клиента не слушает, перебить его нельзя.
- Перевод на оператора пока только фраза и запись в CRM, звонок после неё завершается. Реальный перевод потребует сигнала в dialplan.

## Безопасность

Порт AudioSocket не имеет аутентификации и TLS. Телефонный режим слушает только `TELEPHONY_BIND` (по умолчанию 127.0.0.1) и игнорирует `AUDIOSOCKET_HOST` из `.env`. Asterisk должен работать на том же хосте. Транскрипты звонков печатаются в консоль и содержат персональные данные: не пишите вывод в общий лог без законного основания.

## Что проверено

Тесты запускают настоящий TCP-сервер и клиент, имитирующий Asterisk: фрейминг, пасинг 20 мс, hangup с обеих сторон, лимит звонков, сквозной звонок через настоящий оркестратор. Не проверялись: реальный Asterisk, SIP, качество звука после ресемплинга, распознавание речи по телефонному каналу и задержки.
